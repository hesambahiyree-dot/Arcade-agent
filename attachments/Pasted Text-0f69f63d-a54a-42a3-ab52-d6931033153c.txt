You are an expert full-stack developer. Build a cross-platform AI coding assistant app called "ArcadeAgent" with the following exact architecture.

## Core Concept
A local-first, BYOK (Bring Your Own Key) AI agent that lets users describe an app or game in natural language, and the agent builds it automatically (HTML/CSS/JS). The output runs in a WebView inside the app. The app must work on Windows (Electron) and Android (Capacitor).

## Tech Stack
- Frontend: React + TypeScript + Vite
- Editor: Monaco Editor (@monaco-editor/react)
- Desktop wrapper: Electron + electron-builder
- Mobile wrapper: Capacitor (@capacitor/core, @capacitor/cli, @capacitor/android)
- AI: Google Gemini API via @google/generative-ai (BYOK - user provides key)
- State: Zustand
- Styling: TailwindCSS
- i18n: react-i18next (for English/Persian support)

## Feature 1: Internationalization (i18n)
- Use react-i18next.
- Create two locale files: en.json (English) and fa.json (Persian).
- All UI text must use translation keys.
- Default language must be Persian (fa). RTL layout must be enabled when Persian is selected.
- Add a language switcher in the Settings modal.
- Persist language choice in localStorage.

## Feature 2: Theme System
- Support three theme modes: Light, Dark, and System.
- Default theme is System.
- Use TailwindCSS dark mode with class strategy.
- Add a theme switcher in the Settings modal.
- Persist theme choice in localStorage.

## Feature 3: Chat Panel
- A textarea for the user prompt.
- A "Build" button.
- A message list showing conversation history.

## Feature 4: Agent Core (src/core/agent.ts)
Implement this exact loop:
1. Receive user prompt.
2. Send to Gemini with system instruction + tool definitions.
3. Parse response. If it contains a tool call, execute it.
4. Append tool result to conversation history.
5. Loop until model returns a final text response or max 15 iterations.

System instruction for Gemini:
"You are an expert web developer agent. You build complete web apps using only HTML, CSS, and JavaScript. You have access to tools: create_file, read_file, list_files, edit_file. Always create a working index.html. When done, respond with 'BUILD_COMPLETE'."

## Feature 5: Tools (src/core/tools.ts)
Define these tools:
- create_file(path: string, content: string)
- read_file(path: string)
- list_files(directory: string)
- edit_file(path: string, oldContent: string, newContent: string)

## Feature 6: Gemini Client (src/core/gemini.ts)
- Use @google/generative-ai SDK.
- Support function calling (tools).
- Read API key from keyManager.

## Feature 7: Key Manager (src/core/keyManager.ts)
- Store multiple API keys in localStorage (obfuscated).
- Rotate keys automatically on 429 or 403 errors.
- Track usage count per key.

## Feature 8: Model Selection (IMPORTANT - Use the latest models)
